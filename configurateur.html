Publier sur le site

✅ Aucune clé à saisir. Tu te connectes avec ton compte GitHub — il sert uniquement à prouver qui tu es. C'est le serveur PrepaStrat qui écrit sur le site, après avoir vérifié chaque valeur. Il n'accepte que des couleurs, des nombres et des adresses de vidéo : aucun code ne peut passer par ici.
🔴 Ceci est une maquette, pas le vrai site. Les vraies pages sont sur un autre domaine : impossible de les prévisualiser ici. Les composants sont redessinés avec les mêmes tokens et les mêmes relations qu'en production — mais seul le site fait foi.
